# BRIEF — 01-02 prompt-playground

## 1. 배경

사용자는 로컬 LLM과 Ollama가 처음이고, 이 저장소의 연습 프로젝트들을 통해 익히고 연습하려 한다
(`docs/INTENT.md`). 01-02는 그 학습을 위해 에이전트가 제안한 연습이다. 01-01 local-chat에서 모델과
대화하는 법을 익혔고, 이번에는 같은 프롬프트에 생성 파라미터가 출력에 어떤 영향을 주는지 직접
확인한다. 연습 플랜은 `docs/labs/01-basics/02-prompt-playground.md`에 있다.

이 연습은 학습용이다. 한 번 실험하고 끝나는 것으로 보되, 02-05 prompt-regression이 `seed` 고정을
전제로 하므로 이 PC에서의 `seed` 재현성 검증 결과를 문서로 남겨 02-05의 근거로 쓰게 한다.

## 2. 이번 버전에서 풀고 싶은 문제

같은 프롬프트를 `temperature`·`top_p`·`seed`·시스템 프롬프트만 바꿔 여러 번 실행하고, 결과를
열(column)로 나란히 놓고 비교하는 pywebview 앱을 만든다. 모델은 `qwen3:4b` 하나만 쓴다.

이 과정에서 생성 옵션의 효과, `seed` 고정으로 재현 가능한 출력 만들기, 여러 요청을 순차 실행해
결과를 모으는 방법을 익힌다.

## 4. 하지 않을 것

- 비교 파라미터를 `temperature`·`top_p`·`seed`·시스템 프롬프트 외로 늘리지 않는다.
- 모델을 바꿔 가며 비교하지 않는다. `qwen3:4b` 하나만 쓴다.
- 병렬 요청을 하지 않는다. 변형은 순차 실행한다.
- 변형을 6개보다 많이 실행하지 않는다.
- 결과 품질을 점수로 매기거나 자동 평가하지 않는다.
- 결과를 저장하되, 저장한 것을 불러오거나 이력으로 관리하는 기능은 만들지 않는다.

## 5. 완료 조건

1. 파라미터 조합 N개(최대 6개)를 순차 실행해 결과 N개가 JSON으로 저장된다.
2. 결과 N개가 열로 나란히 보이고, 열마다 파라미터 값·생성 토큰 수·소요 시간이 보인다.
3. 같은 `seed`·`temperature`로 두 번 실행하면 두 출력이 글자 단위로 같은지 화면에 표시된다.
4. 이 PC에서 `qwen3:4b`의 `seed` 재현성을 검증한 결과가 문서로 남는다. 같은 조건을 5회 실행해
   5회 출력이 모두 같은지 다른지를 기록한다.
