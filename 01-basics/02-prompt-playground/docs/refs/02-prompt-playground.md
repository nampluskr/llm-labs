# 01-02 prompt-playground — 파라미터별 출력 나란히 비교

## 1. 개요

같은 프롬프트를 `temperature`·`top_p`·`seed`·시스템 프롬프트만 바꿔 여러 번 실행하고,
결과를 열(column)로 나란히 놓고 비교하는 앱이다. 생성 파라미터가 출력에 주는 영향을 눈으로 확인한다.

- 생성 옵션(`options`)의 종류와 효과
- `seed` 고정으로 재현 가능한 출력 만들기
- 여러 요청을 순차 실행하고 결과를 표로 모으기

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pywebview` |
| Ollama API | `/api/generate`(stream: false) |
| 모델 | `qwen3:4b` 하나(02-05 prompt-regression과 같은 모델) |
| num_ctx | 4096 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 변형 실행 | 파라미터 조합 N개(최대 6개)를 순차 실행해 결과 N개를 JSON으로 저장한다 |
| 2 | 나란히 보기 | 결과 N개가 열로 표시되고, 열마다 파라미터 값·생성 토큰 수·소요 시간이 보인다 |
| 3 | 재현성 표시 | 같은 `seed`·`temperature`로 두 번 실행하면 두 출력이 글자 단위로 같은지 화면에 표시된다 |
| 4 | 재현성 검증 기록 | 같은 조건을 5회 실행해 5회 출력이 모두 같은지 다른지를 기록한 문서가 있다(02-05가 근거로 씀) |

## 4. 하드웨어 메모

- 변형을 순차 실행하므로 한 번에 모델 하나만 올라간다. `qwen3:4b` 예상 VRAM 약 3~3.5GB.
- 병렬 요청(`OLLAMA_NUM_PARALLEL`)은 KV cache를 배로 쓰므로 쓰지 않는다.
