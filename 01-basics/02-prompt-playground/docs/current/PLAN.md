# PLAN — 01-02 prompt-playground

`SPEC`이 없어서 대응 요구는 `BRIEF.md` 5절의 완료 조건 번호를 가리킨다.

## Phase 인덱스

### Phase 1 — 변형 실행

- **목적:** 파라미터 조합을 순차 실행해 결과를 모은다.
- **대응 요구:** BRIEF 완료 조건 1
- **완료 조건:** 파라미터 조합 N개(최대 6개)를 순차 실행해 결과 N개가 JSON으로 저장된다.

### Phase 2 — 나란히 보기

- **목적:** 결과를 열로 나란히 놓고 비교한다.
- **대응 요구:** BRIEF 완료 조건 2
- **완료 조건:** 결과 N개가 열로 표시되고, 열마다 파라미터 값·생성 토큰 수·소요 시간이 보인다.

### Phase 3 — 재현성 표시

- **목적:** 같은 `seed`·`temperature`로 실행한 두 출력이 같은지 화면에서 확인한다.
- **대응 요구:** BRIEF 완료 조건 3
- **완료 조건:** 같은 `seed`·`temperature`로 두 번 실행하면 두 출력이 글자 단위로 같은지 화면에 표시된다.

### Phase 4 — 재현성 검증 기록

- **목적:** 이 PC에서 `qwen3:4b`의 `seed` 재현성을 검증하고 02-05 prompt-regression이 근거로 쓰게 남긴다.
- **대응 요구:** BRIEF 완료 조건 4
- **완료 조건:** 같은 조건을 5회 실행해 5회 출력이 모두 같은지 다른지를 기록한 문서가 있다.
