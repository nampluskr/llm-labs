# HARNESS — 규칙과 강제 장치

프로젝트가 따를 규칙을 설치하고, **기계가 판정할 수 있는 것은 hook으로 막는다.**

`INIT.md` 6·7절이 이 문서를 가리킨다.

---

## 1. 원칙

**규칙과 강제 장치는 쌍이다.**

문서에 적은 규칙 중 기계가 판정할 수 있는 것은 hook이 막는다. 판정할 수 없는
것만 사람과 리뷰어에게 맡긴다.

| 규칙 | 판정 | 어디에 |
| --- | --- | --- |
| `docs/history/` 아래를 고치지 않는다 | 기계 | **hook** |
| `backlog.json`을 직접 편집하지 않는다 | 기계 | **hook** |
| task 완료 시 `PROGRESS.md`에 기록한다 | 기계 | **hook** |
| 요구를 임의로 넓히지 않는다 | 사람 | `CLAUDE.md` · 리뷰어 |
| 완료 조건을 자의적으로 판정하지 않는다 | 사람 | 리뷰어 · **반대 벤더**(`ADVERSARIAL-REVIEW.md`) |
| 구현한 모델이 자기 결과를 판정하지 않는다 | 사람 | **반대 벤더**(`ADVERSARIAL-REVIEW.md`) |

**등록만 하고 동작을 확인하지 않으면 없는 것과 같다.** 5절.

---

## 2. 하네스는 프로젝트 층이다

버전이 올라가도 `.claude/`와 `CLAUDE.md`는 그대로 남는다. `docs/history/`로 가지
않는다.

**[llm-labs]** 하네스는 **저장소 루트에 하나**이고 모든 연습이 공유한다. 아래 표의
"`v0.1` 초기화"는 **저장소의 첫 연습 INIT**을 뜻한다. 그 뒤 다른 연습의 `v0.1` INIT에서는
설치하지 않고 점검과 차단 증명(그 연습 폴더 경로로)만 한다.

| 시점 | 할 것 |
| --- | --- |
| `v0.1` 초기화 | 설치 + 차단 증명 |
| `v0.2`+ 초기화 | **설치하지 않는다.** 승격 항목이 반영됐는지만 확인 |
| 버전 마감 | `DECISIONS.md`에서 승격된 제약을 반영 (`VERSIONING.md` 6절) |

## 3. `CLAUDE.md`

**매 세션 자동 로드된다. 짧아야 읽힌다.**

| 규칙 | 값 |
| --- | --- |
| 분량 | 5~15줄 |
| 담을 것 | **지우면 실수가 생기는 줄**만 |
| 담지 않을 것 | 설명, 배경, 일반론, 코딩 스타일 취향 |

첫 줄에 가이드 버전을 적는다.

```
project-workflow v0.2 기준으로 초기화됨 (2026-09-07)
```

가이드가 갱신되면 예전에 초기화한 프로젝트와 구조가 달라진다. 기록이 없으면
나중에 왜 다른지 알 수 없다.

승격된 제약에는 출처를 남긴다.

```
- torch 버전을 올리지 않는다 (v0.1 D-3)
```

**불어나면 안 읽힌다.** 승격은 사람이 승인한다. 원본은 `templates/CLAUDE.md`.

## 4. `.claude/`

| 대상 | 담는 것 |
| --- | --- |
| `rules/` | 경로별 금지 규칙. **첫 줄에 "막는 사고"를 적는다** |
| `hooks/` | 차단·검사 스크립트 |
| `agents/` | 리뷰어 subagent |
| `settings.json` | hook 등록 |

### `rules/`

경로에 걸리는 규칙만 둔다. 전역 규칙은 `CLAUDE.md`다.

첫 줄이 "이 규칙이 막는 사고"여야 한다. 무엇을 금지하는지만 적으면 나중에
사람이 그 규칙을 지울지 판단할 수 없다.

### `hooks/`

셋을 건다.

| # | 시점 | 막는 것 |
| --- | --- | --- |
| 1 | `PreToolUse` | `docs/history/` 아래 기존 파일 수정·삭제 |
| 2 | `PreToolUse` | `backlog.json` 직접 편집 — CLI로만 |
| 3 | `Stop` | task를 닫았는데 `PROGRESS.md`에 기록이 없음 |

1번과 2번이 핵심이다. 기록이 사후에 바뀌는 것과 SSOT가 무너지는 것을 막는다.

3번은 "문서를 안 고치고 코드만 수정"을 막는다. 진행이 커밋에만 남고 사람이
읽을 수 없게 되는 것을 방지한다.

원본은 `templates/claude/hooks/`에 있다 — `guard.mjs`(1·2번), `progress-check.mjs`(3번).
**복사해서 쓰되 경로는 프로젝트에 맞게 확인한다.** 목록은 `templates/INDEX.md`.

**[llm-labs]**
- `guard.mjs`는 원본 그대로다. 경로에 `/docs/history/`가 들어 있는지로 판정하므로
  연습 폴더 안의 `NN-category/NN-name/docs/history/`도 막는다.
- `progress-check.mjs`는 고쳤다. 연습 폴더마다 따로 판정한다 — 그 연습의 `docs/` 밖 파일이
  바뀌었는데 그 연습의 `docs/current/PROGRESS.md`가 그대로면 막는다. 저장소 루트 파일은
  판정하지 않는다. 새 폴더가 하나로 뭉쳐 보이지 않게 `git status --porcelain -uall`을 쓴다.

### `agents/`

리뷰어 하나면 시작하기에 충분하다. 역할은 **적대적 검증**이다.

| 볼 것 | 보지 않을 것 |
| --- | --- |
| 완료 조건을 실제로 충족했나 | 코딩 스타일 |
| `SPEC`의 요구 ID와 맞나 | 취향 |
| 범위를 넘어선 것이 있나 | 이미 hook이 막은 것 |

**"통과"를 기본값으로 두지 않는다.** 근거를 대지 못하면 미충족이다.

**여기서 끝이 아니다.** 이 리뷰어는 구현자와 **같은 벤더·같은 세션**이라, 구현할 때
놓친 것을 검토할 때도 놓친다. 그 상관을 끊는 층이 따로 있다 — **반대 벤더 적대적
검증**(`ADVERSARIAL-REVIEW.md`). 순서는 `hook → 이 리뷰어 → 반대 벤더`이고, 새 기능
구현과 **리팩토링에는 반대 벤더 검증이 필수**다. 이 리뷰어가 그것을 대신하지 않는다.

## 5. 차단 증명 — negative control

**등록된 것과 동작하는 것은 다르다.** 경로 오타, 실행 권한, 종료 코드 문제로
조용히 무력화되는 일이 흔하다.

설치 직후 가짜 입력으로 확인한다.

| # | 시도 | 기대 |
| --- | --- | --- |
| 1 | `docs/history/` 아래 파일에 한 글자 쓰기 | **차단** |
| 2 | `backlog.json`을 편집기로 직접 수정 | **차단** |
| 3 | `docs/current/BRIEF.md` 읽기 | 통과 |
| 4 | **[llm-labs]** 이 연습 폴더의 코드 파일만 바꾸고 Stop hook(`progress-check.mjs`) 실행 | **차단**(종료 코드 2) |
| 5 | **[llm-labs]** 4번에 이어 그 연습의 `docs/current/PROGRESS.md`도 바꾸고 다시 실행 | 통과 |

**[llm-labs]** 1~5번의 경로는 모두 이번에 초기화하는 연습 폴더 아래로 잡는다
(예: `01-basics/01-local-chat/docs/history/…`). 1번은 history 아래에 **이미 있는 파일**이어야
막힌다 — 새 파일 생성은 마감 스냅샷 때문에 허용한다. 증명용으로 만든 파일과 변경은 증명
뒤에 지운다.

3번이 있는 이유 — 막히기만 하고 통과가 안 되면 그것도 고장이다. **막을 것을 막고
통과할 것을 통과시키는지** 둘 다 본다.

**하나라도 기대와 다르면 초기화 실패다.** 보고하고 멈춘다. 여기서 넘어가면
남은 절차가 전부 무의미하다.

증명 결과를 보고에 적는다.

```
| 시도 | 기대 | 결과 |
| history 수정 | 차단 | 차단됨 |
| backlog 직접 편집 | 차단 | 차단됨 |
| current 읽기 | 통과 | 통과 |
```

## 6. 흔한 실패

| 증상 | 원인 |
| --- | --- |
| hook이 등록됐는데 안 막힌다 | `settings.json` 경로 오타. 절대 경로로 확인 |
| 전부 막힌다 | 매처가 너무 넓다. 경로 조건 확인 |
| 조용히 통과한다 | 스크립트가 오류로 죽고 종료 코드가 0. 직접 실행해 본다 |
| Windows에서만 안 된다 | 경로 구분자. `\`와 `/`를 둘 다 처리 |

**세 번째가 가장 위험하다.** 막히는 것처럼 보이지 않고 그냥 아무 일도 안 일어난다.
그래서 5절이 필요하다.
