## 3. 착수할 때 넘길 것

해당 연습을 착수(INIT)할 때 그 연습의 BRIEF로 옮긴다.

- **00-01·00-02**
  - Ollama 설치와 모델 받기는 사용자가 직접 한다. 에이전트는 읽기 전용 명령으로 확인만 한다.
  - 00-01에서 설치를 마친 뒤 가이드의 기록표를 채운다. 02-01의 예상값 보정이 이 값에서 출발한다.
- **01-01**
  - 공통 코드는 다른 연습을 예상해 미리 넓히지 않는다. 01-01·02-01에 실제로 필요한 것만 만든다.
  - 공통 코드는 저장소 루트에 `shared\`로 두지 않는다. 쓰는 연습이 자기 폴더로 복사해 쓴다(연습끼리 독립).
- **02-01**
  - `docs/refs/03-project-list.md`·`docs/refs/01-hardware.md`의 VRAM·속도 예상값을 실측치로 바꾼다.
  - 연습 플랜 파일(37개)은 고치지 않는다. 각 연습을 착수할 때 고친다.
  - `qwen3:30b`(MoE, VRAM을 넘는 오프로드 모델)를 반드시 측정한다.
