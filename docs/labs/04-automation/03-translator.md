# 04-03 translator — 용어집 고정 한↔영 번역기

## 1. 개요

한국어↔영어 번역 데스크톱 앱이다. 왼쪽 원문, 오른쪽 번역문을 문단 단위로 맞춰 보여 주고,
용어집(원어→번역어)을 지정하면 번역에서 그 용어를 지키게 한다. 붙여 넣은 텍스트뿐 아니라
**영어 문서 파일(md·txt·pdf)을 열어 구조를 유지한 채 한국어로 번역하고 파일로 저장**한다.
PDF는 텍스트를 추출해 마크다운으로 재구성한 뒤 같은 방식으로 번역한다.
모든 UI는 pywebview로 만든다(저장소 DECISIONS R-9).

- 번역용 시스템 프롬프트와 용어집 주입
- 문단 단위 분할 번역과 정렬 보기
- 용어 준수 여부 자동 검사
- 마크다운 구조(제목·목록·표·코드 블록·링크) 유지 번역과 긴 문서의 앞 문맥 유지
- PDF 텍스트 추출과 문단 재구성(줄바꿈 병합, 머리글·꼬리글·쪽 번호 제거, 글자 크기로 제목 추정)

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pywebview`, `markdown-it-py`(마크다운 구조 분해·재조립), `pymupdf`(PDF 텍스트·글자 크기·위치 추출) |
| Ollama API | `/api/chat`(stream) |
| 모델 | `exaone3.5:7.8b`(한국어), `qwen3:8b`(비교). 번역 특화 비교 대상: `translategemma:4b`(3.3GB, 번역 전용, 한국어 포함 55개 언어), `translategemma:12b`(8.1GB), `aya-expanse:8b`(5.1GB, 다국어 23개, 한국어 포함) |
| num_ctx | 4096(문단 단위 + 직전 문단 요약) |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 번역 | 원문을 붙여 넣고 방향(한→영 / 영→한)을 고르면 문단 수가 같은 번역문이 스트리밍으로 나온다 |
| 2 | 대조 보기 | 원문 문단을 클릭하면 대응하는 번역 문단이 강조된다 |
| 3 | 용어집 | 용어집 CSV를 불러오면 번역문에서 용어집 항목의 사용 여부가 표시되고, 위반 문단 수가 출력된다 |
| 4 | 문서 파일 번역 | 영어 md 파일을 열어 번역하면 `<이름>.ko.md`가 저장된다. 원본과 번역본의 제목 수·목록 항목 수·표 수·코드 블록 수·링크 수가 같고, 코드 블록과 링크 URL은 글자 그대로 같다. 시험 문서 3건(1만 단어 이상 1건 포함)으로 확인한다 |
| 5 | PDF 번역 | 텍스트 PDF를 열면 먼저 재구성한 영어 `<이름>.en.md`를 저장하고, 이를 Phase 4 방식으로 번역해 `<이름>.ko.md`를 저장한다. 시험 PDF 3건(1단·2단 레이아웃 각 1건 이상)에서 머리글·꼬리글·쪽 번호가 본문에 남지 않고, 문장 중간의 줄바꿈·하이픈 끊김이 이어 붙여진다(사람이 쪽 3개씩 대조). 텍스트가 없는 스캔 PDF는 "텍스트 없음 — 06-04 scan-ocr로 먼저 추출"을 알리고 번역하지 않는다 |

## 4. 하드웨어 메모

- `exaone3.5:7.8b` 예상 VRAM 약 5.5GB. 긴 문서도 문단 단위로 보내 컨텍스트를 작게 유지한다.
- 긴 문서는 문단 수에 비례해 시간이 걸린다. 진행률(번역한 문단 / 전체)을 표시하고, 중단 후 이어서 번역할 수 있게 한다. 실제 속도는 02-01 결과로 추정한다.
- 코드 블록·인라인 코드·URL은 모델에 보내지 않고 자리표시자로 바꿨다가 되돌린다. 모델이 코드를 번역하거나 고치는 일을 막는다.
- PDF 추출·재구성은 CPU에서 하고 LLM을 쓰지 않는다. 표·수식·그림 속 글자는 재구성이 깨지기 쉬우므로, 이 프로젝트는 본문 문단과 제목만 보장한다.
- 스캔 PDF의 OCR은 범위 밖이다. 06-04 scan-ocr가 만든 `<이름>.ocr.md`를 이 앱의 md 입력으로 번역한다.
- 비교 대상 모델(`01-hardware.md` 5.2절):
  - `translategemma`는 정해진 프롬프트 형식("You are a professional {SOURCE_LANG} ({SOURCE_CODE}) to
    {TARGET_LANG} ({TARGET_CODE}) translator. …" 뒤에 빈 줄 두 개와 원문)을 써야 한다. 다른 모델과 같은
    시스템 프롬프트를 쓰지 않는다.
  - `translategemma:12b`는 VRAM 경계라 일부 CPU 오프로드를 전제로 한다(`gemma3:12b`와 같은 크기).
  - `aya-expanse:8b`는 최대 컨텍스트가 8K다. 이 앱의 `num_ctx` 4096 안에서는 문제없다.
  - Pascal(1080 Ti)에서 도는지와 속도는 설치 후 확인한다.
