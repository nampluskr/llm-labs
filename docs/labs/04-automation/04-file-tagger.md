# 04-04 file-tagger — 폴더 파일 분류·이름 변경 제안

## 1. 개요

폴더의 텍스트 문서를 읽어 분류(카테고리), 태그, 새 파일 이름을 **제안**하는 앱이다. 제안은 표로 보이고,
사람이 행마다 승인한 것만 실제로 이름을 바꾸거나 하위 폴더로 옮긴다. 되돌리기 로그를 남긴다.
LLM 판단을 파일 시스템 변경에 연결할 때 안전장치를 두는 연습이다.

- 분류 프롬프트와 고정 카테고리 목록
- 제안 → 승인 → 적용 → 되돌리기 흐름
- 일괄 처리 진행률과 실패 행 처리

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pydantic`, `pywebview` |
| Ollama API | `/api/chat`(`format` JSON 스키마) |
| 모델 | `qwen3:4b` |
| num_ctx | 4096(파일 앞부분 3,000자 정도만 입력) |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 제안 생성 | 시험 폴더(파일 20개)에서 파일마다 카테고리·태그·새 이름이 담긴 제안 JSON이 생성된다. 파일은 하나도 바뀌지 않는다 |
| 2 | 승인·적용 | 표에서 승인한 행만 이름이 바뀌고, 적용 로그(원래 경로→새 경로)가 저장된다 |
| 3 | 되돌리기 | 로그로 되돌리면 시험 폴더의 파일 목록이 적용 전과 같다 |

## 4. 하드웨어 메모

- 파일마다 짧은 요청이라 `qwen3:4b`로 충분하다.
- 시험은 반드시 복사본 폴더에서 한다.

## 5. 미정

- 대상 파일 종류(텍스트만 / PDF 포함)
