# 04-02 json-extractor — 자유 텍스트에서 스키마 JSON 추출

## 1. 개요

자유 텍스트(메일, 메모, 공지문)에서 미리 정한 스키마(일정, 연락처, 주문 등)에 맞는 JSON을 뽑아내는
CLI다. Ollama의 구조화 출력(`format`에 JSON 스키마)을 쓰고, pydantic으로 다시 검증한다.
다른 프로젝트(02-04 채점, 06-05 영수증, 07-04 backlog)가 재사용할 추출 함수를 만든다.

- pydantic 모델 → JSON 스키마 → `format`
- 스키마 검증 실패 시 재시도
- 정답 세트로 필드별 정확도 측정

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI(재사용 가능한 모듈 + 얇은 CLI) |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pydantic` |
| Ollama API | `/api/chat`(`format`: JSON 스키마) |
| 모델 | `qwen3:8b`, `qwen3:4b`(비교) |
| num_ctx | 4096 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 단일 스키마 | 일정 스키마(제목·날짜·시간·장소) 하나로 입력 10건을 추출하고, 결과 10건이 모두 pydantic 검증을 통과한다 |
| 2 | 스키마 3종 | 스키마를 `--schema` 옵션으로 고르고(일정·연락처·주문), 정답 JSON 대비 필드별 정확도 표가 나온다 |
| 3 | 재시도 | 검증 실패 시 오류 메시지를 덧붙여 최대 2회 재시도하고, 최종 실패 건수를 출력한다 |

## 4. 하드웨어 메모

- 구조화 출력은 생성 중 문법 제약을 걸어 속도가 조금 떨어질 수 있다. 02-01 방식으로 tok/s를 같이 기록한다.
