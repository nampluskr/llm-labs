# 04-01 commit-writer — git diff로 커밋 메시지 초안

## 1. 개요

스테이징된 변경(`git diff --cached`)을 읽어 커밋 메시지 초안(제목 한 줄 + 본문)을 만드는 CLI다.
초안을 보여 주고, 사람이 승인하면 그 메시지로 커밋한다. 짧은 입력 → 정해진 형식의 짧은 출력이라는
가장 단순한 자동화 형태다.

- diff 입력 크기 제한과 요약
- 출력 형식 강제(제목 길이, 본문 불릿)
- 사람 승인 단계를 둔 자동화

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama`, `subprocess`(git 호출) |
| Ollama API | `/api/chat`(`format` JSON 스키마: subject, body) |
| 모델 | `qwen3:4b` |
| num_ctx | 8192(diff 입력) |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 초안 생성 | `commit-writer`가 스테이징된 diff로 subject(72자 이하)와 body를 출력한다. 스테이징이 비어 있으면 종료 코드 1 |
| 2 | 승인·커밋 | 초안 확인 후 `y`면 `git commit -F`로 커밋되고, `e`면 편집기로 고친 뒤 커밋된다 |
| 3 | 큰 diff | 8K 토큰을 넘는 diff는 파일별로 요약한 뒤 합쳐 초안을 만든다. 테스트용 큰 diff 1건으로 확인한다 |

## 4. 하드웨어 메모

- 4B 모델로 충분하다. 예상 VRAM 약 3~3.5GB, 응답은 수 초로 예상한다.
- 커밋 메시지 언어(한국어/영어)는 레포 관례를 따르게 옵션으로 둔다.
