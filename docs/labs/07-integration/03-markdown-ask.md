# 07-03 markdown-ask — 문서 읽기 + 요약·질문 창

## 1. 개요

md 파일(또는 폴더)을 열어 렌더링해 보여 주고, 옆 패널에서 그 문서를 요약하거나 질문하는 독립
pywebview 앱이다. 기존 `markdown-viewer`를 고치지 않고, 같은 일을 하는 작은 앱을 이 저장소 안에
따로 만든다. 주 대상은 `D:\projects`에 쌓인 기획·설계 문서이며 **읽기만 한다.**
결과가 쓸 만하면 `markdown-viewer`의 새 버전으로 옮겨 갈지 연습을 끝낸 뒤 판단한다(INTENT 3절).

- 문서 길이에 따라 "전체 넣기"와 "검색 후 넣기" 전환
- 답의 근거 위치를 렌더링 화면에서 강조
- 03-01 doc-qa의 청크 검색 모듈 재사용

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview |
| 언어·패키지 | Python 3.13(uv), `ollama`, `numpy`, `pywebview`, 마크다운 렌더링은 JS(`marked`) |
| Ollama API | `/api/chat`(stream), 긴 문서는 `/api/embed` |
| 모델 | `qwen3:8b`, `bge-m3` |
| num_ctx | 8192 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 열기·렌더링 | md 파일을 열면 렌더링되고, 폴더를 열면 왼쪽 목록에서 md 파일을 골라 볼 수 있다. 앱은 어떤 파일도 쓰지 않는다 |
| 2 | 요약 | "요약" 버튼으로 패널에 스트리밍 요약이 나온다. Ollama가 꺼져 있으면 안내 메시지를 보이고 문서 보기는 정상 동작한다 |
| 3 | 질문·근거 | 문서에 대한 질문에 답하고, 근거 문단을 클릭하면 렌더링 화면이 그 위치로 스크롤되며 강조된다 |
| 4 | 긴 문서 | 8K 토큰을 넘는 문서는 청크 검색으로 근거를 골라 답한다. 시험 문서 1건으로 확인한다 |

## 4. 하드웨어 메모

- `qwen3:8b` + `bge-m3` 예상 VRAM 약 7.5GB. 앱이 열려 있는 동안 모델을 계속 올려 두지 않는다(기본 `keep_alive`).
