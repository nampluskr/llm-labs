# 07-02 youtube-digest — 유튜브 자막 요약·챕터

## 1. 개요

`youtube-kit`으로 영상 자막을 받아, 요약·핵심 문장·챕터(타임코드 + 제목)를 만드는 도구다.
자막이 없는 영상은 `youtube-kit`으로 음성을 받아 `speech_transcriber`로 전사한 뒤 같은 처리를 한다.
이미 만든 두 도구를 파이프라인으로 잇고 그 끝에 LLM을 붙인다.

- 기존 CLI(`youtube-kit`)를 파이프라인 단계로 호출
- 타임코드가 있는 텍스트에서 챕터 경계 찾기
- 결과를 마크다운 문서로 내기

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama`, `youtube-kit`(CLI 호출), `pydantic` |
| Ollama API | `/api/chat`(`format`: 챕터 목록) |
| 모델 | `qwen3:8b`, `exaone3.5:7.8b`(한국어 영상) |
| num_ctx | 8192 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 자막 받기 | URL 하나로 `youtube-kit`을 호출해 자막 파일을 받고, 자막이 없으면 종료 코드로 알린다 |
| 2 | 요약·챕터 | `digest.md`에 요약, 핵심 문장 5개, 챕터 목록이 있고, 모든 챕터 타임코드가 영상 길이 안에 있다 |
| 3 | 자막 없는 영상 | 음성 → `speech_transcriber` → 같은 처리로 `digest.md`가 나온다 |

## 4. 하드웨어 메모

- 긴 영상(1시간 이상)의 자막은 8K 컨텍스트를 넘는다. 구간별 요약 후 합친다(03-04와 같은 방식).

## 5. 미정

- 결과를 `youtube-downloader`의 새 버전으로 옮길지(INTENT 3절) — 연습을 끝낸 뒤 판단
