# 02-04 ko-eval — 한국어 문항 세트 모델 비교

## 1. 개요

정답이 정해진 한국어 문항(상식, 맞춤법, 간단한 계산, 요약 핵심어 포함 여부 등)을 JSONL로
만들어 모델별 정답률을 내는 CLI다. "한국어 작업에 어느 모델을 쓸까"를 감이 아니라 점수로 정한다.

- 평가 세트 설계(문항, 정답, 채점 규칙)
- 규칙 채점(정확 일치·포함·숫자)과 LLM 채점의 차이
- 구조화 출력(`format`)으로 답 형식 고정

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pydantic` |
| Ollama API | `/api/chat`(`format` JSON 스키마) |
| 모델 | `exaone3.5:7.8b`, `qwen3:8b`, `qwen3:4b`(채점 모델은 피평가 모델과 다르게) |
| num_ctx | 4096 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 평가 세트 | `items.jsonl`에 문항 50개 이상, 각 문항에 `id`·`question`·`answer`·`grader`(exact / contains / number / llm)가 있다 |
| 2 | 규칙 채점 | 모델 3개 × 문항 전체 실행 후 모델별 정답률과 문항별 맞음·틀림 CSV가 나온다 |
| 3 | LLM 채점 | `grader: llm` 문항을 다른 모델이 채점하고, 사람이 20문항을 골라 확인한 일치율을 기록한다 |

## 4. 하드웨어 메모

- 모델을 하나씩 순서대로 돌리고, 바꿀 때 이전 모델을 내린다.
- 50문항 × 3모델이면 8B 기준 수 분 단위로 예상한다. 실제 시간은 02-01 결과로 추정한다.

## 5. 미정

- 문항 출처(직접 작성 / 공개 평가 세트 일부 발췌)
