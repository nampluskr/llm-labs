# 02-05 prompt-regression — 프롬프트 변경 스냅샷 테스트

## 1. 개요

프롬프트 템플릿을 고칠 때 기존 입력들의 출력이 어떻게 달라지는지 pytest로 확인하는 하네스다.
`seed`와 `temperature: 0`으로 출력을 고정하고, 스냅샷 파일과 비교해 바뀐 케이스만 보고한다.
다른 프로젝트(04-02 json-extractor 등)의 프롬프트를 지키는 테스트 도구로 쓴다.

- LLM 출력의 결정성 확보(seed, temperature, 모델 태그 고정)
- 스냅샷 테스트와 "의도된 변경" 승인 흐름
- 정확 일치 대신 구조 비교(JSON 키, 필수 단어)

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python(pytest) |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pytest` |
| Ollama API | `/api/generate`(options.seed, temperature 0) |
| 모델 | `qwen3:4b` |
| num_ctx | 4096 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 결정성 확인 | 같은 입력을 5번 실행해 출력 5개가 모두 같은지 결과를 기록한다(같지 않으면 원인을 기록) |
| 2 | 스냅샷 | 케이스 10개로 `pytest`가 처음엔 스냅샷을 만들고, 두 번째 실행은 10 passed |
| 3 | 변경 감지 | 템플릿 한 줄을 바꾸면 바뀐 케이스만 실패로 나오고, `--update-snapshots`로 승인하면 다시 전부 통과한다 |

## 4. 하드웨어 메모

- GPU 연산 순서 차이로 seed를 고정해도 출력이 미세하게 달라질 수 있다. Phase 1에서 이 PC의 결정성을 먼저 확인한다.
- Ollama 버전이나 모델 태그가 바뀌면 스냅샷이 무효가 된다. 스냅샷에 두 값을 같이 기록한다.
