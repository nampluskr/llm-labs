# 03-01 doc-qa — 로컬 문서 근거 질의응답

## 1. 개요

폴더 하나의 md·txt·pdf 문서를 청크로 나눠 `bge-m3`로 임베딩하고, 질문이 오면 가까운 청크를
찾아 LLM에게 넘겨 답하게 하는 앱이다. 답 아래에 근거 청크(파일명·위치)를 함께 보여 준다.
RAG의 가장 기본 형태를 벡터 DB 없이 numpy만으로 만든다.

- 청크 분할(크기·겹침)과 임베딩
- numpy 코사인 유사도 top-k 검색
- 근거만으로 답하게 하는 프롬프트와 "모르면 모른다"

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview |
| 언어·패키지 | Python 3.13(uv), `ollama`, `numpy`, `pypdf`, `pywebview` |
| Ollama API | `/api/embed`, `/api/chat`(stream) |
| 모델 | 임베딩 `bge-m3`, 생성 `qwen3:8b` 또는 `exaone3.5:7.8b` |
| num_ctx | 8192(근거 청크 5개 + 질문) |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 색인 | `index <폴더>`가 청크 텍스트·출처·벡터를 `.npz` + `.jsonl`로 저장하고, 청크 수와 소요 시간을 출력한다 |
| 2 | 검색 | 질문 10개에 대해 top-5 청크를 출력한다. 사람이 미리 정한 정답 청크가 top-5에 든 비율을 기록한다 |
| 3 | 답변 | 답 아래에 근거 청크가 출처와 함께 표시된다. 문서에 없는 질문 3개에는 "문서에 없음"으로 답한다 |
| 4 | 화면 | pywebview에서 폴더 선택 → 색인 → 질문 → 스트리밍 답변 + 근거 펼치기가 한 화면에서 된다 |

## 4. 하드웨어 메모

- `bge-m3`(약 1.2GB)와 `qwen3:8b`(약 6GB)를 동시에 올려도 예상 합계 약 7.5GB로 여유 안이다. 설치 후 `ollama ps`로 두 모델이 모두 100% GPU인지 확인한다.
- 청크 1만 개 × 1024차원 float32 ≈ 40MB이므로 numpy 메모리 검색으로 충분하다.
