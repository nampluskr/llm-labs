# 03-05 paper-reader — 논문 PDF 읽기 도우미

## 1. 개요

논문 PDF 하나를 열면 섹션을 나누고, 섹션별 요약·전체 요약·용어집을 만들고, 특정 섹션을 근거로
질문할 수 있는 앱이다. 왼쪽은 섹션 트리, 가운데는 원문 텍스트, 오른쪽은 요약·질의 패널이다.
03-01의 RAG에 문서 구조(섹션)를 더한다.

- PDF 텍스트 추출과 섹션 경계 찾기
- 섹션 단위 RAG(검색 범위 제한)
- 용어집 같은 구조화 출력

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview |
| 언어·패키지 | Python 3.13(uv), `ollama`, `numpy`, `pymupdf`, `pydantic`, `pywebview` |
| Ollama API | `/api/embed`, `/api/chat`(stream, `format`) |
| 모델 | `bge-m3`, `qwen3:8b` |
| num_ctx | 8192 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 섹션 분할 | 시험용 논문 3편에서 추출한 섹션 제목 목록이 원문 목차와 사람이 비교해 일치한다 |
| 2 | 요약·용어집 | 섹션별 요약과 용어집 JSON(용어·정의·처음 나온 섹션)이 생성된다 |
| 3 | 질의 | 섹션을 지정한 질문은 그 섹션의 청크만 근거로 쓰고, 근거 위치가 표시된다 |
| 4 | 화면 | 3단 화면에서 섹션 선택 → 원문 이동 → 요약 표시가 연동된다 |

## 4. 하드웨어 메모

- 수식·표는 텍스트 추출이 깨지기 쉽다. 이 프로젝트는 본문 텍스트만 다루고 수식 해석은 하지 않는다.
- 03-01과 같은 모델 조합이라 예상 VRAM 약 7.5GB.
