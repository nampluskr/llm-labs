# 03-02 projects-search — 워크스페이스 문서 의미 검색

## 1. 개요

`D:\projects` 아래의 문서(md 중심)를 의미로 검색하는 탐색기·탭 앱이다. 왼쪽 트리는 프로젝트별
폴더, 검색 결과를 고르면 문서가 탭으로 열리고 해당 청크로 스크롤된다. 생성 모델 없이 임베딩
검색만 쓰고, 바뀐 파일만 다시 색인하는 증분 색인을 익힌다.

- 파일 수정 시각·해시 기반 증분 색인
- 키워드 검색과 의미 검색의 결과 차이
- `tab-explorer-templates`의 교체 지점에 도메인 기능 끼우기

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview(`tab-explorer-templates` NumPy 갈래에서 출발) |
| 언어·패키지 | Python 3.13(uv), `ollama`, `numpy`, `pywebview` |
| Ollama API | `/api/embed` |
| 모델 | `bge-m3` |
| num_ctx | 해당 없음(임베딩 입력은 청크 단위, 최대 8K) |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 전체 색인 | `_archive`·`_clones`·`node_modules`·`.git`을 제외하고 색인해 파일 수·청크 수를 출력한다 |
| 2 | 증분 색인 | 파일 1개를 고친 뒤 다시 색인하면 그 파일의 청크만 다시 임베딩된다(로그의 재임베딩 파일 수 = 1) |
| 3 | 화면 | 검색어 입력 → 결과 목록(파일·점수·미리보기) → 선택 시 탭으로 열리고 해당 위치가 강조된다 |

## 4. 하드웨어 메모

- 임베딩 모델만 쓰므로 예상 VRAM 약 1.5GB. 다른 LLM과 함께 올려도 부담이 적다.
- 첫 전체 색인은 문서 양에 비례해 오래 걸린다. 진행률을 표시하고 중단·재개할 수 있게 한다.

## 5. 미정

- 색인 대상 확장자(md만 / txt·py 포함)
