# 03-04 repo-digest — 코드 저장소 요약과 README 초안

## 1. 개요

코드 저장소를 파일 단위로 요약하고, 그 요약들을 폴더 단위 → 저장소 단위로 다시 요약해
구조 설명과 README 초안을 만드는 CLI다. 컨텍스트에 다 안 들어가는 큰 입력을 계층 요약
(map-reduce)으로 다루는 방법을 익힌다.

- 파일 필터(.gitignore 존중, 바이너리 제외)
- map-reduce 요약과 단계별 캐시
- 결과를 사람이 검토하는 초안으로 내기

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pathspec`(.gitignore 해석) |
| Ollama API | `/api/generate` |
| 모델 | `qwen3:8b` |
| num_ctx | 8192 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 파일 요약 | 대상 레포의 모든 소스 파일에 대해 요약 JSON(파일·역할·주요 함수)이 생성되고, 다시 실행하면 바뀐 파일만 요약한다 |
| 2 | 계층 요약 | 폴더별 요약과 저장소 요약이 `digest.md`로 나온다 |
| 3 | README 초안 | `README.draft.md`가 개요·구조·실행 방법 절을 갖고 생성된다. 실제 README와 사람이 비교한 메모를 남긴다 |

## 4. 하드웨어 메모

- 파일 하나가 8K 토큰을 넘으면 잘라서 요약한다.
- 파일 수가 많으면 시간이 길다. `backlog`(작은 레포)로 먼저 시험한다.
