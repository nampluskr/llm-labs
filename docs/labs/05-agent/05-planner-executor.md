# 05-05 planner-executor — 계획 세우고 단계별로 실행·검토

## 1. 개요

큰 요청("이 폴더의 문서들을 읽고 주제별 요약 보고서 만들어줘")을 받으면 먼저 단계 계획(JSON)을
세우고, 단계마다 도구를 써서 실행하고, 결과를 검토해 계획을 고치거나 다음 단계로 넘어가는 CLI다.
05-01의 루프 위에 계획·검토 층을 얹는다. 사람이 계획을 승인한 뒤에 실행한다.

- 계획 생성 → 승인 → 실행 → 검토 루프
- 단계별 상태 저장과 중단 후 재개
- 작은 모델에서 계획이 무너지는 지점 관찰

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pydantic` |
| Ollama API | `/api/chat`(`tools`, `format`) |
| 모델 | `qwen3:8b` |
| num_ctx | 8192 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 계획 | 요청 5개에 대해 단계 목록 JSON(단계·사용 도구·완료 기준)이 생성되고, 사람이 승인·수정할 수 있다 |
| 2 | 실행 | 승인된 계획을 단계별로 실행하고 단계마다 결과와 상태를 `run.json`에 기록한다 |
| 3 | 검토·재개 | 실패한 단계는 검토 후 계획을 고쳐 다시 실행한다. 중간에 끊은 실행을 `--resume`으로 이어서 끝낸다 |

## 4. 하드웨어 메모

- 8B 모델의 계획 능력에는 한계가 있다. 단계 수를 최대 7개로 제한하고, 넘으면 요청을 쪼개라고 안내한다.
- 단계마다 대화를 새로 시작하고 필요한 결과만 넘겨 컨텍스트를 작게 유지한다.
