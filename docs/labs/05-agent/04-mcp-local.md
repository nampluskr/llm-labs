# 05-04 mcp-local — 로컬 모델에 MCP 서버 연결

## 1. 개요

MCP(Model Context Protocol) 클라이언트를 직접 만들어, MCP 서버(파일 시스템 서버 등)가 제공하는 도구
목록을 Ollama의 `tools` 형식으로 바꿔 넘기고, 모델의 도구 호출을 MCP 서버로 중계하는 CLI다.
05-01에서 직접 만든 도구를 표준 프로토콜의 도구로 바꾼다.

- MCP 도구 목록(`tools/list`)·호출(`tools/call`)
- MCP 도구 스키마 → Ollama `tools` 변환
- stdio로 서버 프로세스 실행·종료

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama`, `mcp`(공식 Python SDK) |
| Ollama API | `/api/chat`(`tools`) |
| 모델 | `qwen3:8b` |
| num_ctx | 8192 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 연결 | MCP 서버 하나에 stdio로 연결해 도구 목록(이름·설명)을 출력한다 |
| 2 | 중계 | 질문 5개에 대해 모델의 도구 호출이 MCP 서버로 전달되고 결과로 답한다. 호출 로그가 남는다 |
| 3 | 서버 여러 개 | 설정 파일의 서버 2개를 동시에 붙이고, 도구 이름 충돌 시 서버 이름을 앞에 붙여 구분한다 |

## 4. 하드웨어 메모

- MCP 도구 설명이 많으면 프롬프트가 길어진다. 도구 수 × 설명 길이를 출력해 컨텍스트 사용량을 확인한다.
- 파일 시스템 서버는 시험 폴더로 범위를 제한해 띄운다.

## 5. 미정

- 시험에 쓸 MCP 서버(파일 시스템 서버 외 1개)
