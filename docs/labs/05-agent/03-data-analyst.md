# 05-03 data-analyst — CSV 질문에 코드로 답하는 분석 도우미

## 1. 개요

CSV 파일을 열고 "월별 매출 추이 보여줘" 같은 질문을 하면, 모델이 pandas 코드를 만들고 앱이 그
코드를 별도 프로세스에서 실행해 결과 표와 Plotly 차트로 보여 주는 앱이다. 실행 오류가 나면 오류를
모델에 돌려주고 고치게 한다. 사용자가 익숙한 numpy·pandas·Plotly 작업에 LLM을 붙인다.

- 데이터 스키마(열 이름·타입·예시 행)만 프롬프트에 넣기
- 생성 코드를 제한된 별도 프로세스에서 실행(시간 제한, 쓰기 금지 폴더)
- 오류 → 수정 반복 루프

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview(Plotly.js) |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pandas`, `numpy`, `plotly`, `pywebview` |
| Ollama API | `/api/chat` |
| 모델 | `qwen3:8b` |
| num_ctx | 8192 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 코드 생성 | 예제 CSV와 질문 10개에 대해 생성된 코드가 `df`만 입력으로 쓰고 `result`(표 또는 Plotly figure)를 만든다 |
| 2 | 격리 실행 | 생성 코드가 별도 프로세스에서 30초 제한으로 실행되고, 넘으면 중단된다. 파일 쓰기를 시도하는 코드는 실행 전에 거부된다 |
| 3 | 오류 수정 | 실행 오류가 난 경우 최대 2회 수정해 성공한 비율을 기록한다 |
| 4 | 화면 | 질문 → 코드(접기) → 결과 표·차트가 한 화면에 쌓인다 |

## 4. 하드웨어 메모

- 생성 코드 실행은 CPU에서 한다. LLM은 코드 생성에만 쓴다.
- 생성 코드 실행은 안전하지 않다. 이 PC의 개인 데이터 폴더 밖, 복사본 CSV로만 시험한다.
