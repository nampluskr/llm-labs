# 05-01 tool-agent — 도구를 골라 호출하는 기본 에이전트

## 1. 개요

계산기, 현재 시각, 파일 찾기, 텍스트 파일 읽기 같은 도구 4~5개를 정의해 두고, 질문에 따라 모델이
도구를 골라 호출하고 그 결과로 답하게 하는 CLI다. 프레임워크 없이 tool calling 루프를 직접 만든다.

- `tools` 정의(JSON 스키마)와 `tool_calls` 응답 처리
- 도구 결과를 `role: tool` 메시지로 돌려주는 반복 루프
- 최대 반복 횟수·읽기 전용 도구로 안전 범위 정하기

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama` |
| Ollama API | `/api/chat`(`tools`) |
| 모델 | `qwen3:8b`(tool calling 지원) |
| num_ctx | 8192 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 도구 1개 | 계산기 도구 하나로 "37*91은?"에 도구 호출 → 결과 → 답 순서가 로그에 찍힌다 |
| 2 | 도구 여러 개 | 도구 5개, 질문 10개 중 사람이 정한 "올바른 도구"를 고른 비율을 출력한다 |
| 3 | 다단계 | 두 도구를 연이어 써야 하는 질문 3개를 최대 5회 반복 안에 해결하고, 넘으면 중단 메시지를 낸다 |

## 4. 하드웨어 메모

- 반복할 때마다 대화가 길어지므로 `num_ctx` 8192를 기본으로 한다.
- 도구는 읽기 전용만 둔다. 쓰기·실행 도구는 05-02에서 확인 단계와 함께 다룬다.
