# 05-02 shell-helper — 자연어로 PowerShell 명령 제안

## 1. 개요

"이 폴더에서 100MB 넘는 파일 찾아줘" 같은 요청을 PowerShell 명령으로 바꿔 **제안**하는 CLI다.
명령과 설명, 위험도(읽기 / 변경 / 삭제)를 보여 주고, 사람이 승인해야 실행한다. 변경·삭제 명령은
한 번 더 확인한다. 에이전트가 실제 시스템을 건드릴 때의 안전장치를 익힌다.

- 명령 생성 + 위험도 분류 구조화 출력
- 위험 명령 규칙 검사(`Remove-Item`, `-Recurse`, `Format-*` 등)
- 실행 결과를 다시 모델에 넣어 다음 단계 제안

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pydantic`, `subprocess`(`powershell -NoProfile -Command`) |
| Ollama API | `/api/chat`(`format` JSON 스키마) |
| 모델 | `qwen3:8b` |
| num_ctx | 4096 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 제안만 | 요청 20개에 대해 명령·설명·위험도를 출력하고 실행하지 않는다. 사람이 판정한 정확도를 기록한다 |
| 2 | 승인 실행 | `y` 입력 시에만 실행하고 출력을 보여 준다. 위험도 "삭제" 명령은 명령 전체를 다시 입력해야 실행된다 |
| 3 | 규칙 검사 | 모델이 "읽기"로 분류했어도 규칙 목록에 걸리는 명령은 위험도가 올라간다. 시험 명령 10개로 확인한다 |

## 4. 하드웨어 메모

- 시험은 복사본 폴더에서 한다. 작업 폴더를 지정하는 옵션을 두고, 그 밖의 경로가 들어간 명령은 경고한다.
