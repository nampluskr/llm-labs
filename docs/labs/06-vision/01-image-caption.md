# 06-01 image-caption — 이미지 폴더 설명·태그 일괄 생성

## 1. 개요

이미지 폴더를 지정하면 이미지마다 한 문장 설명과 태그 5개를 만들어 JSONL로 저장하는 CLI다.
비전 모델에 이미지를 넣는 가장 기본적인 방법(`images`에 base64)을 익히고, 06-03 photo-search의 입력 데이터를 만든다.

- 비전 입력(`messages[].images`)
- 큰 이미지 축소 후 입력(속도·메모리)
- 이미 처리한 파일은 건너뛰는 일괄 처리

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pillow`, `pydantic` |
| Ollama API | `/api/chat`(`images`, `format`) |
| 모델 | `gemma3:4b`(비전) |
| num_ctx | 4096 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 한 장 | 이미지 1장에 대해 설명·태그 JSON이 출력되고, 이미지당 소요 시간이 표시된다 |
| 2 | 폴더 | 이미지 50장 폴더 처리 후 JSONL 50행, 다시 실행하면 0장 처리(모두 건너뜀) |
| 3 | 품질 확인 | 사람이 20장을 골라 설명이 맞는지 판정한 비율을 기록하고, 한국어·영어 설명을 비교한다 |

## 4. 하드웨어 메모

- `gemma3:4b`는 비전 처리부가 포함되어 같은 크기의 텍스트 모델보다 VRAM을 더 쓴다. 예상 약 4~5GB, 설치 후 실측한다.
- 이미지는 긴 변 1024px 정도로 줄여 넣는다.
- `gemma3:12b`도 비전을 지원하지만 GPU 적재 "경계"(01-hardware 5.2절)이므로 비교용으로만 쓴다.
