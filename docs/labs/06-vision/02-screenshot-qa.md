# 06-02 screenshot-qa — 화면 캡처에 질문하기

## 1. 개요

`Win+Shift+S`로 캡처한 이미지를 앱에 붙여 넣고 "이 오류 창이 무슨 뜻이야?", "이 표를 정리해줘"처럼
질문하는 pywebview 앱이다. 대화가 이어지는 동안 같은 이미지를 문맥으로 유지한다.

- 클립보드 이미지 읽기(pywebview JS → 파이썬)
- 이미지 + 텍스트 다중 턴 대화
- 화면 글자 읽기(OCR 성격) 정확도 확인

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pillow`, `pywebview` |
| Ollama API | `/api/chat`(stream, `images`) |
| 모델 | `gemma3:4b` |
| num_ctx | 8192(이미지 토큰 포함) |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 붙여 넣기 | `Ctrl+V`로 붙여 넣은 캡처가 미리보기로 보이고, 질문하면 스트리밍 답이 나온다 |
| 2 | 다중 턴 | 같은 이미지에 후속 질문 3개를 이어 해도 이미지를 다시 붙이지 않고 답한다 |
| 3 | 글자 읽기 | 오류 창·코드 캡처 10장에서 "화면의 글자를 그대로 옮겨줘" 결과와 실제 글자를 사람이 비교한 일치 정도를 기록한다 |

## 4. 하드웨어 메모

- 고해상도 캡처(4K 화면)는 줄여서 넣는다. 너무 줄이면 작은 글자를 못 읽으므로 Phase 3에서 축소 크기를 정한다.
