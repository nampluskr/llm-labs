# 06-03 photo-search — 문장으로 사진 찾기

## 1. 개요

06-01이 만든 사진 설명·태그를 `bge-m3`로 임베딩해 두고, "바다에서 찍은 노을 사진" 같은 문장으로
사진을 찾는 pywebview 앱이다. 결과는 썸네일 격자로 보여 준다. 비전(설명 생성)과 임베딩 검색을 잇는다.

- 이미지 → 텍스트 → 임베딩의 2단계 색인
- 설명 품질이 검색 품질을 좌우하는 것 확인
- 썸네일 캐시와 격자 화면

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python + pywebview |
| 언어·패키지 | Python 3.13(uv), `ollama`, `numpy`, `pillow`, `pywebview` |
| Ollama API | `/api/embed` |
| 모델 | `bge-m3`(검색), 설명은 06-01 결과 재사용 |
| num_ctx | 해당 없음 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 색인 | 06-01의 JSONL을 읽어 사진마다 설명+태그 임베딩을 `.npz`로 저장한다 |
| 2 | 검색 | 검색 문장 10개에 대해 top-10 사진을 출력하고, 사람이 정한 정답 사진이 top-10에 든 비율을 기록한다 |
| 3 | 화면 | 검색어 입력 → 썸네일 격자 → 클릭 시 원본과 설명이 보인다 |

## 4. 하드웨어 메모

- 검색 시점에는 `bge-m3`만 쓰므로 VRAM 부담이 적다. 비전 모델은 색인을 만들 때만 쓴다.
