# 06-05 receipt-scanner — 영수증 이미지 → JSON

## 1. 개요

영수증 사진에서 상호, 날짜, 품목(이름·수량·금액), 합계를 JSON으로 뽑는 CLI다. 04-02 json-extractor의
스키마·검증·재시도 모듈을 그대로 쓰고, 입력만 텍스트에서 이미지로 바꾼다.
합계 = 품목 금액 합이라는 규칙으로 결과를 스스로 검증한다.

- 04-02 모듈 재사용(입력 종류만 교체)
- 규칙 기반 자기 검증(합계 대조)
- 사진 품질(기울기, 흐림)이 결과에 주는 영향

## 2. 기술 스택

| 항목 | 내용 |
| --- | --- |
| 런타임 | Python CLI |
| 언어·패키지 | Python 3.13(uv), `ollama`, `pillow`, `pydantic`, 04-02 추출 모듈 |
| Ollama API | `/api/chat`(`images`, `format`) |
| 모델 | `gemma3:4b` |
| num_ctx | 4096 |

## 3. 간단한 플랜

| Phase | 목적 | 완료 조건 |
| --- | --- | --- |
| 1 | 추출 | 영수증 사진 10장에서 스키마 검증을 통과한 JSON 10개가 나온다 |
| 2 | 자기 검증 | 품목 합 ≠ 합계인 결과를 표시하고, 그 건만 재시도한다. 재시도 전후 불일치 건수를 출력한다 |
| 3 | 내보내기 | 여러 영수증을 CSV 한 파일로 모으고, 사람이 정답과 비교한 필드별 정확도를 기록한다 |

## 4. 하드웨어 메모

- 시험용 영수증 사진은 개인정보(카드 번호 등)가 보이지 않는 것만 쓴다.
