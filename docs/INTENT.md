# INTENT — llm-labs

## 1. 무엇을 하는가

Ollama로 이 PC에서 돌리는 로컬 LLM을 활용하는 연습 프로젝트들을 한 저장소에 모아, 하나씩
구현하며 익힌다. 실제로 쓰는 완성형 프로젝트와 분리된 연습 공간이다.

## 2. 왜 하는가

지금까지 Windows 데스크톱 앱(Electron·pywebview)을 만들며 연습해 왔고, 다음 주제로 로컬 LLM을
직접 다뤄 보고 싶다. 연습용 코드가 실제로 쓰는 완성형 프로젝트들 사이에 흩어지면 관리가
어려우니, 연습은 한곳에 모아 실사용 프로젝트와 분리한다.

## 3. 변하지 않는 원칙

- LLM은 이 PC에서 Ollama로 돌린다. 클라우드 LLM API를 연습의 런타임으로 쓰지 않는다.
- 연습은 문서(플랜)를 먼저 갖추고, 그 문서를 근거로 하나씩 구현한다.
- 연습 저장소 안에서 실사용 프로젝트를 고치지 않는다. 기존 앱과 잇는 연습은 결과가 쓸 만하면
  해당 레포의 새 버전으로 옮겨 간다.
- 구현과 리팩토링은 project-workflow를 llm-labs에 맞게 고친 절차(`workflow/`)를 따르고, 반대 벤더
  적대적 검증을 거친다.

## 4. 다루지 않는 것

- 완성형 제품으로 다듬거나 배포하는 일. 이 저장소는 연습 공간이다.
- Ollama 외의 LLM 런타임(llama.cpp 직접 사용, LM Studio 등)으로 연습하는 일.
- 모델을 학습시키거나 파인튜닝하는 일. 받은 모델을 쓰기만 한다.
- 이 PC 밖(서버·클라우드·다른 기기)에서 돌리는 일.
