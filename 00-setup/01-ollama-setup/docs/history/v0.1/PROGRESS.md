# PROGRESS — 00-01 ollama-setup

## 계획된 작업

### Phase 1 — 설치 (2026-10-04)

- **무엇을:** 사용자가 설치 가이드 1~3단계로 Ollama를 직접 설치했다. 에이전트는 읽기 전용으로 확인만 했다.
- **결과:** 설치됨. 경로 `C:\Users\nampl\AppData\Local\Programs\Ollama\ollama.exe`.
- **검증:** `ollama --version` → `ollama version is 0.35.1` (완료 조건 0.35.1 이상 충족). 설치 전에는 `ollama` 명령을 찾지 못했다. 설치 직후 이 세션의 셸은 PATH를 새로 읽어야 인식했다.

### Phase 2 — GPU 동작 확인 (2026-10-04)

- **무엇을:** 사용자가 `ollama run qwen3:4b`로 모델을 받아 적재했다. 에이전트는 `ollama ps`·`nvidia-smi`를 읽기 전용으로 확인하고, 사용자 요청으로 확인된 값을 기록표에 옮겼다.
- **결과:** `qwen3:4b`가 `100% GPU`로 적재됨(3.2 GB, 컨텍스트 4096). 적재 중 VRAM 5043 MiB.
- **검증:** `ollama ps` → PROCESSOR `100% GPU`. 기록표(`docs/refs/02-ollama-install-guide.md`)에 설치 날짜·방법·버전·실행 중 VRAM·PROCESSOR를 채움.
- **받기 전 VRAM(4-1):** 사용자가 모델 적재 전에 측정한 1839 MiB를 기록표에 적었다(처음 단계에서 측정하지 못해 한동안 "미측정"으로 두었다가, 사용자가 적재 전에 잰 값을 제시해 바꿨다). 적재 중 5043 MiB와 약 3.2 GB 차이다.
- **남은 칸:** 초당 생성 토큰·로그 오류는 Phase 3과 5단계에서 채운다.

### Phase 3 — API 확인 (2026-10-04)

- **무엇을:** 사용자가 설치 가이드 6-1의 `/api/generate` 호출(`qwen3:4b`, `stream:false`)을 직접 실행했다. 에이전트는 사용자가 붙여 준 출력을 확인했다.
- **결과:** 응답 문자열 `1+1은 2입니다. …`이 나왔다. `eval_count` 401, `eval_duration` 5499488000 ns, `load_duration` 3768100 ns. 초당 생성 토큰은 401 / 5.4995 ≈ 72.9 tok/s.
- **검증:** 완료 조건(응답 문자열 + 세 값 모두 0 초과) 충족. 에이전트가 호출을 직접 실행하지 않고 사용자가 붙여 준 출력으로 판정했다. `load_duration`이 3.8 ms로 작은 것은 모델이 이미 적재돼 있었기 때문이다.

### Phase 4 — 연습용 모델 받기 (2026-10-04) — 부분 완료, 모델별 적재 확인은 사용자 결정으로 생략

- **무엇을:** 사용자가 `ollama pull`로 모델 6개를 받았다(`qwen3:4b`는 Phase 2에서 받음). 에이전트는 `ollama list`와 `/api/tags`를 읽기 전용으로 확인했다.
- **결과:** 7개가 모두 받아져 있다. `qwen3:4b`, `qwen3:8b`, `exaone3.5:7.8b`, `bge-m3:latest`, `gemma3:12b`, `qwen3:14b`, `qwen3:30b`. 서버는 `/api/tags`에 응답한다.
- **검증:** 완료 조건 중 "7개가 `ollama list`에 있다"와 "01-01이 쓰는 `qwen3:8b`·`qwen3:4b`·`exaone3.5:7.8b`가 목록에 있고 서버가 `/api/tags`에 응답한다"는 충족.
- **미충족:** "모델마다 적재했을 때의 PROCESSOR 값이 기록표에 있다"는 충족하지 못했다. 사용자가 `qwen3:4b` 외 6개 모델의 적재 테스트를 생략하기로 했다. 기록표 7단계 칸에는 "미측정 (적재 테스트 생략)"을 적었다. PLAN의 완료 조건은 바뀌지 않았으므로 Phase 4는 PLAN 기준으로 완료가 아니다. 이 조건을 어떻게 처리할지(조건 수정 또는 후속 연습으로 이월)는 사람이 정한다. 모델별 적재·VRAM 실측은 02-01 model-bench가 다룬다.
