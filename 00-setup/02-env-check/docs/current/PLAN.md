# PLAN — 00-02 env-check

SPEC은 두지 않는다. Phase마다 BRIEF 5절 완료 조건을 가리킨다. Phase 1~3의 완료 조건은 연습 플랜
(`docs/labs/00-setup/02-env-check.md` 3절)과 같다.

환경은 D-2·D-6을 따른다(이 연습 폴더의 uv 프로젝트, Python 3.13, CUDA·winpython 미사용). 점검은 읽기 전용
API만 쓴다(D-3).

## Phase 1 — 파이썬 환경

- **목적:** 이 연습 폴더의 uv 환경에서 pywebview와 jupyter가 실제로 동작하는지 확인한다(D-1, D-2).
- **BRIEF 완료 조건:** "연습 플랜의 Phase 1~3 완료 조건을 모두 만족한다"
- **완료 조건:** 이 연습 폴더에서 `uv sync`가 끝나고, pywebview 창이 뜨며, jupyter 커널로 셀 한 개가 실행된다.

## Phase 2 — Ollama 점검

- **목적:** 읽기 전용 API로 Ollama 서버 상태를 점검한다(D-3, D-4).
- **BRIEF 완료 조건:** "연습 플랜의 Phase 1~3 완료 조건을 모두 만족한다", "서버가 꺼져 있을 때 `env-check`가 오류
  문구와 종료 코드 1을 낸다"
- **완료 조건:** `env-check`가 Ollama 서버 연결·버전·받은 모델 목록·적재된 모델과 PROCESSOR를 출력하고, 서버를
  껐을 때는 오류 문구와 종료 코드 1을 낸다.

## Phase 3 — 요약 출력

- **목적:** 점검 결과를 항목별 통과/실패와 전체 결과로 요약하고, `--json`으로도 낸다(D-5).
- **BRIEF 완료 조건:** "연습 플랜의 Phase 1~3 완료 조건을 모두 만족한다", "점검 항목마다 통과/실패 한 줄과 전체
  결과가 출력되고, `--json`이 같은 내용을 낸다"
- **완료 조건:** 점검 항목마다 통과/실패 한 줄과 전체 결과를 출력하고, `--json`으로 같은 내용을 JSON으로 낸다.

## 적대적 검증

이 연습은 새 기능을 구현하므로 검증 대상이다(`workflow/docs/ADVERSARIAL-REVIEW.md` 3절). 절차는 그 문서를
따르고, 여기에는 이 연습에서만 정해지는 것을 적는다.

- **필수 통과 Phase:** Phase 2 — 미해결 Critical이 있으면 Phase 3으로 넘어가지 못한다. 사람이 정했다(2026-10-04)
- **Phase별 공격 초점:**
  - Phase 1 — 환경이 실제로 만들어지고 창·커널이 뜨는가. 다른 Python 버전이나 `.venv` 없는 상태에서도 3.13으로
    고정되는가
  - Phase 2 — 서버가 꺼졌거나 모델이 없거나 적재된 모델이 없을 때 깨지는가. 점검이 모델을 적재하지는 않는가
  - Phase 3 — `--json` 출력이 화면 출력과 같은 내용인가. 항목 하나가 실패해도 나머지가 출력되고 종료 코드가
    맞는가
